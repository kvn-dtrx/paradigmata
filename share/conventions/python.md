# Python Conventions

Encoding, file header, and comment style follow [plain-text.md](plain-text.md).
The body of a Python module or script is organised with the following section
markers (omit empty sections):

```python
# --- Imports ---

{{{…}}}

# --- Configuration ---

{{{…}}}

# --- Auxiliary Code ---

{{{…}}}

# --- Main Code ---

{{{…}}}
```
